Rules that always apply

  • Nobody checks or approves their own file.The person who adds a file cannot be its checker or approver.
  • Checker and approver are two different people.Two sign-offs, by two people, before a file counts as current.
  • Every step needs a reason.Adding, changing, removing or moving a file asks why, in writing.
  • Nothing is erased.Removing a file marks it deleted and renames it. It can be restored.
  • Every action is written down.Who did what, when, and why. The record cannot be edited.
  • Old versions stay on record.When a new version is approved, the old one is kept, marked as replaced.
